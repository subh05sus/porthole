# Support

## Got a question?

Check the [FAQ](FAQ.md) first — it covers the questions that come up most (safety, permissions, how porthole compares to `lsof`/`fkill-cli`/`npx kill-port`, the auto-kill daemon, firewall rules, the web dashboard).

Still stuck? [Open an issue](https://github.com/subh05sus/porthole/issues/new/choose) — there's no separate discussions forum yet, so general questions are welcome there too, not just bug reports.

## Found a bug?

[Open an issue](https://github.com/subh05sus/porthole/issues/new/choose) using the bug report template. Include your porthole version (`porthole --version`), OS/architecture, and exact steps to reproduce — see the template for the full list.

## Found a security issue?

**Don't open a public issue.** See [SECURITY.md](SECURITY.md) for private reporting.

## Want to contribute?

See [CONTRIBUTING.md](CONTRIBUTING.md) for the project structure, testing expectations, and which areas get extra scrutiny (the kill ladder, firewall rules, the auto-kill daemon).

## Commercial support

None offered at this time — porthole is maintained on a best-effort basis.
